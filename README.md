# 🌟 Random Quote Generator

A simple and responsive **Random Quote Generator** web application built using HTML, CSS, and JavaScript. This app displays a collection of inspiring quotes along with their authors, featuring a sleek design and an interactive button to generate new quotes dynamically.

---

## 🚀 Features

* **Dynamic Quote Generation:** Displays a random quote and author from an array of curated quotes upon clicking the button.
* **Modern UI/UX:** Clean card layout styled with CSS, utilizing Flexbox for alignment and FontAwesome icons.
* **DOM Manipulation:** Seamlessly updates the HTML content using vanilla JavaScript.
* **Interactive Event Handling:** Listens for click events on the "New Quote" button to trigger updates instantly.

---

## 🛠️ Technologies Used

* **HTML5:** For structuring the webpage elements.
* **CSS3:** For styling, layout design (Flexbox), and responsiveness.
* **JavaScript (ES6):** For arrays, random number generation, DOM manipulation, and event handling.
* **FontAwesome:** For visual icons.
